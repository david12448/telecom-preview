# Shared governance snapshot

Central source: david12448/project-common-rules/COMMON_RULES.md (PR #1).

- Protect nonpublic source registries, collectors, parsers, raw data, credentials and internal mappings. Public pages should expose only necessary normalized information. Prefer server-side pagination and reasonable rate limits; URL hiding is not security. Respect attribution and lawful access.
- Record verified errors, causes, attempted fixes, validation and prevention in docs/TROUBLESHOOTING.md. Never invent historical incidents.
- Preserve existing files and functionality; use reviewed PRs. No automatic progress notifications.

This is a one-time snapshot, not yet automatically synced.
